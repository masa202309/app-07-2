# 🤖 キッズロボット シミュレーター

生成AIを活用した子供向けインタラクティブロボットシミュレーションアプリです。

## ✨ 機能

### 1. ロボット制御
- **方向ボタン**: ⬆️⬇️⬅️➡️ でロボットを自由に動かせます
- **ストップボタン**: ⏹️ でロボットを停止します
- **クリック移動**: キャンバスをクリックすると、その場所にロボットが自動で移動します

### 2. アクション機能
- 💃 **ダンス**: ロボットがくるくる回転しながら踊ります
- 🦘 **ジャンプ**: ロボットがジャンプします
- 🌀 **回転**: ロボットがスピンします
- 👋 **手を振る**: ロボットが手を振ります

### 3. AI対話システム
AIを使った自然言語処理で、ロボットと日本語で会話できます：

#### 対応コマンド例
- 「こんにちは」→ ロボットが挨拶を返します
- 「踊って」→ ダンスを実行します
- 「ジャンプして」→ ジャンプします
- 「回って」→ 回転します
- 「手を振って」→ 手を振ります
- 「上に行って」→ 上に移動します
- 「ありがとう」→ お礼を返します

### 4. ビジュアルエフェクト
- ✨ **パーティクルエフェクト**: アクション時にカラフルなパーティクルが表示されます
- 🎨 **軌跡表示**: ロボットの移動経路が表示されます
- 🌈 **グラデーション**: 美しいカラーグラデーションUIデザイン
- 😊 **エモーション表示**: ロボットの感情が絵文字で表示されます

### 5. ステータス管理
- 📊 **移動回数**: ロボットが移動した回数をカウント
- 🎯 **アクション回数**: 実行したアクション数をカウント
- ⚡ **エネルギー**: ロボットのエネルギーレベルを表示
- 🎭 **気分**: ロボットの気分をランダム表示

### 6. サウンドエフェクト
- Web Audio APIを使用した効果音
- 移動時とアクション時に異なるサウンドが再生されます

## 🚀 使い方

### 起動方法
1. `index.html` をブラウザで開く
2. すぐに遊べます！（サーバー不要）

### 推奨環境
- モダンブラウザ (Chrome, Firefox, Safari, Edge)
- JavaScript有効
- 画面解像度: 1280x800以上推奨

## 🎮 遊び方

### 基本操作
1. **矢印ボタン**でロボットを動かす
2. **アクションボタン**でロボットにアクションさせる
3. **キャンバスをクリック**してロボットを移動させる

テキストボックスに日本語で命令を入力すると、ロボットがAIで理解して動きます：

```
例1: "踊って" → ロボットがダンスします
例2: "上に行って" → ロボットが上に移動します
例3: "元気？" → ロボットが元気に返事します
```

## 🔧 OpenAI API設定

### APIキーの取得方法
1. [OpenAI Platform](https://platform.openai.com/) にアクセス
2. アカウントを作成またはログイン
3. API Keys ページから新しいAPIキーを作成
4. `sk-` で始まるAPIキーをコピー

### APIキーの設定手順
1. アプリを開く
2. 「⚙️ AI設定」をクリック
3. APIキーを入力して「保存」ボタンをクリック
4. ✅ が表示されたら設定完了

### トラブルシューティング

#### ❌ CORS エラーが発生する場合

ブラウザのセキュリティ制限により、ローカルファイルから直接OpenAI APIにアクセスできません。

**解決方法:**

**方法1: ローカルサーバーで実行（推奨）**
```bash
# Pythonがインストールされている場合
python -m http.server 8000
# または
python3 -m http.server 8000

# ブラウザで http://localhost:8000 を開く
```

**方法2: Node.jsのhttp-serverを使用**
```bash
# http-serverをインストール
npm install -g http-server

# サーバーを起動
http-server -p 8000

# ブラウザで http://localhost:8000 を開く
```

**方法3: VSCodeのLive Server拡張を使用**
- VSCodeで「Live Server」拡張機能をインストール
- index.htmlを右クリック → "Open with Live Server"

#### ❌ 認証エラー（401）が発生する場合
- APIキーが正しく入力されているか確認
- APIキーが有効か確認（OpenAI Platform で確認）
- APIキーの先頭に `sk-` があるか確認

#### ❌ レート制限エラー（429）が発生する場合
- OpenAIの使用量制限に達しています
- しばらく待ってから再試行
- OpenAI Platformでプランを確認

#### ❌ サーバーエラー（500, 503）が発生する場合
- OpenAI側で一時的な問題が発生しています
- しばらく待ってから再試行
- [OpenAI Status](https://status.openai.com/) で状態を確認

### セキュリティに関する注意

⚠️ **重要**: APIキーは機密情報です

- **公開しないこと**: GitHubなどにAPIキーをコミットしない
- **共有しないこと**: 他人とAPIキーを共有しない
- **ローカル環境で使用**: 本番環境では使用しない
- **定期的に更新**: 定期的にAPIキーを再生成する

このアプリはクライアントサイド（ブラウザ）でAPIキーを使用するため、教育目的やローカル環境での使用に限定してください。本番環境では、バックエンドサーバーを経由してAPIを呼び出すことを推奨します。

## 🛠️ 技術仕様

### 使用技術
- **HTML5 Canvas**: ロボットとエフェクトの描画
- **JavaScript (Vanilla)**: ロボットのロジックとAI制御
- **CSS3**: グラデーション、アニメーション、レスポンシブデザイン
- **Web Audio API**: サウンドエフェクト生成

### アーキテクチャ

#### Robot クラス
```javascript
- draw(): ロボットと環境を描画
- move(direction): 方向指定で移動
- dance(), jump(), spin(), wave(): アクションメソッド
- createParticles(): パーティクルエフェクト生成
- updateStats(): ステータス更新
```

#### AIController クラス
```javascript
- sendCommand(): ユーザー入力を処理
- processCommand(): コマンドをAI解析
- addMessage(): チャットメッセージ追加
- responses: パターンマッチング辞書
```

#### Particle クラス
```javascript
- update(): パーティクルの物理演算
- ライフサイクル管理
```

### AI機能の仕組み

このアプリのAIは**パターンマッチング**と**自然言語理解**を組み合わせています：

1. **キーワード抽出**: ユーザー入力から重要なキーワードを検出
2. **意図推定**: キーワードから行動を推定
3. **応答生成**: コンテキストに応じた返答を生成
4. **アクション実行**: 推定した行動を実行

例：
- 入力: "踊って" → キーワード: "踊" → アクション: dance()
- 入力: "上に行って" → キーワード: "上" → アクション: move('up')

## 🎨 カスタマイズ

### ロボットの色を変更
```javascript
// index.html の Robot.draw() メソッド内
ctx.fillStyle = '#667eea'; // この色コードを変更
```

### 速度調整
```javascript
// Robot クラスのコンストラクタ
this.speed = 5; // 数値を変更（大きいほど速い）
```

### AI応答を追加
```javascript
// AIController クラスの responses オブジェクトに追加
'新しいキーワード': ['応答1', '応答2', '応答3']
```
